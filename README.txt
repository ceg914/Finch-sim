Finch-Sim 앱 패키지 — 휴대폰 홈 화면에 앱처럼 설치하기
=====================================================

이 폴더를 통째로 https 웹 주소에 올리면, 휴대폰에서 아이콘이 있는 앱으로 설치할 수 있어요.
(휴대폰은 보안상 내 파일을 바로 '앱'으로 설치하지 못해서, 웹 주소가 한 번 필요합니다.)

1) 올리기 — 예: GitHub Pages
   · github.com 에서 새 저장소(public)를 만들고 이 폴더 안의 파일을 모두 올립니다.
     (index.html, manifest.webmanifest, sw.js, icons 폴더)
   · 저장소 Settings → Pages → Branch 를 main 으로 선택하고 Save.
   · 잠시 뒤 https://아이디.github.io/저장소이름/ 주소가 생깁니다.

2) 휴대폰에 설치
   · 아이폰: Safari로 주소 열기 → 공유 버튼 → '홈 화면에 추가'
   · 안드로이드: Chrome으로 주소 열기 → 메뉴(⋮) → '앱 설치' 또는 '홈 화면에 추가'

3) 한 번 열어 두면 그다음부터는 인터넷이 없어도 실행됩니다.

※ 컴퓨터에서 테스트: 이 폴더에서  python -m http.server 8000  실행 후
   브라우저로 http://localhost:8000 을 열면 됩니다.
